# Alien Invasion

A Python arcade-style shooting game built with **Pygame** to demonstrate strong **Object-Oriented Programming (OOP)** skills and game development fundamentals.

This project was created as a showcase of Python programming ability and OOP design — including classes for game entities, clean game loop structure, and interactive gameplay mechanics.

---

## About The Game

In *Alien Invasion*, you control a spaceship that defends Earth from waves of descending aliens. The game is inspired by classic arcade shooters and follows a dynamic gameplay loop:

- Move your ship left and right
- Fire bullets at alien enemies
- Survive multiple waves as the difficulty increases
- Track scores and gameplay states

Each game element is represented as its own class, exemplifying OOP best practices and modular design.

---

## Features

* Written in Python 3 using **Pygame**  
* Fully object-oriented architecture  
* Player ship with movement controls  
* Shooting mechanics and bullet handling  
* Alien fleet with movement and collision detection 
* Game state tracking (start, play, end)  
* Clean code structure
